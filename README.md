# Project-2 Filatova M26-555

## Установка

Для установки пакета и всех зависимостей выполните:

    uv sync

Или установите собранный wheel-файл:

    uv tool install dist/project-2_filatova_m26_555-0.1.0-py3-none-any.whl

## Запуск

Запуск базы данных осуществляется командой:

    database

## CRUD-операции

В базе данных реализованы следующие команды для управления записями. Cтолбец `ID` генерируется автоматически, и при вставке (`insert`) его указывать не нужно.

- `create_table <имя_таблицы> <столбец1:тип> ...` — создать новую таблицу. Разрешенные типы: `int`, `str`, `bool`.
- `insert into <имя_таблицы> values (<значение1>, <значение2>, ...)` — создать новую запись (значения передаются строго для всех столбцов, кроме `ID`).
- `select from <имя_таблицы> where <столбец> = <значение>` — прочитать записи, соответствующие условию.
- `select from <имя_таблицы>` — прочитать все записи таблицы.
- `update <имя_таблицы> set <столбец1> = <новое_значение1> where <столбец_условия> = <значение>` — обновить существующие записи.
- `delete from <имя_таблицы> where <столбец> = <значение>` — удалить записи, соответствующие условию.
- `info <имя_таблицы>` — вывести информацию о структуре таблицы и количестве записей.
- `drop_table <имя_таблицы>` — удалить таблицу целиком.
- `help` — вывести справку по всем командам.
- `exit` — выйти из программы.
